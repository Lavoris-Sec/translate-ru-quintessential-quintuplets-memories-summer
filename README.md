# goto-ru

Личный проект русификации **The Quintessential Quintuplets – Five Memories Spent With You**.

В репозитории лежат только созданные для перевода материалы: PowerShell-скрипты и JSON-патчи. Файлы игры, её архивы, резервные копии и сторонние утилиты намеренно не публикуются.

## Что уже переведено

- `op_01` — вступление;
- `ca01_01` — ночной разговор с Итикой;
- `ca01_02` — планы на день и пляжная ветка;
- `ca01_03` — сцена на пляже и разговор с Итикой.

## На другом компьютере

1. Установить игру через Steam.
2. Клонировать этот репозиторий.
3. Скачать те же утилиты FreeMote Toolkit и извлечь архивы игры в локальную рабочую папку.
4. Применить JSON-патчи из `translation` к распакованным сценариям скриптом `scripts/Apply-DialogueBlock.ps1`.
5. Пересобрать `scenario_info.psb.m` и `scenario_body.bin` с помощью `PsBuild.exe`.
6. Перед заменой файлов в `windata` сохранить оригинальные `scenario_info.psb.m` и `scenario_body.bin`.

Никогда не запускайте Steam-проверку целостности, если хотите сохранить локальный патч: она вернёт оригинальные архивы игры.
